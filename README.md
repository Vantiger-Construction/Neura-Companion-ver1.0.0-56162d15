# Neura Companion 🤖✨

![version](https://img.shields.io/badge/version-v1.0.0-purple)

Neura Companion is an animated, AI-powered mood tracker that glows, evolves, and reflects based on your emotional state. She talks, dances, remembers your vibe, and becomes your daily check-in buddy.

> “Your mood just got a companion.”

---

## 🔥 Live Site
[👉 Visit Neura Companion](https://neura.app) *(Firebase Hosting)*  
🌐 [Neura Companion Mirror (GitHub Pages)](https://Vantiger1.github.io/neura-companion)

---

## ✨ Features
- Adaptive AI personality (sass, warmth, empathy)
- Mood tracker with graph history
- Emotional journaling with reflections
- Real-time voice interaction + tone
- Glowing idle mascot that reacts + dances to music
- Firebase sync + offline support (PWA-ready)

---

## 🧠 Tech Stack
- Flutter + Dart
- Firebase Hosting
- Lottie/Rive animations
- Flutter TTS
- LocalStorage / Shared Preferences

---

## 📦 Run Locally
```bash
flutter pub get
flutter run
```

## 🌍 Build for Web
```bash
flutter build web
firebase deploy
```
